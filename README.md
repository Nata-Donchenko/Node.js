Вимога 2
Обрано окрема роль/прапорець is_owner.
Створювати товари можуть лише користувачі з is_owner = true,
а кожен товар через owner_id посилається на свого власника.

Тобто, права у продавців та покупців різні.

Роль/прапорець задаються під час реєстрації


Вимога 5
Обрано комбінований підхід.
Мова і валюта є обовязковими налаштуваннями для всіх користувачів.
Зберігаються окремими колонками, за якими зручно робити пошук чи фільтрацію

Інші налаштування опціональні. 
Лежать у колонці settings типу JSON, бо мають довільну структуру за вкладеністю.
