1. У HTTP взаємодія будується "запит клієнта-відповідь сервера". Після обміну інформацією взаємодія закінчується. WebSocket встановлює зєднання один раз і воно залишається відкритим як для клієнта, так і для сервера. У таком увипадку сервер сам може надслати дані клієнту без запиту
2. ws:// це WebSocket зєднання без шифрування, тобто дані передаються у відкритому вигляді і є незахищенними.
wss:// це WebSocket зєднання поверх TLS із застосуванням відповдіних вимог щодо довіри
3. Цей код перебирає всіх користувачів і надсилає кожному.
 wss.clients.forEach((client) => {
    client.send(message);
  });

  Треба зробити ідентифікацію конкретного користувача при підключенні шляхом присвоєння ІД (для прикладу) і замість перебору всіх користувачів знайти потрібного за ідентифікатором і викликати send тільки на ньому

  4. Тому що час повинен бути доступним одночасно усім підключеним користувачам з урахуванням часових поясів. Якщо час буде додавати клієнт, то він буде відображатись по його локальному часу, до того ж ці дані будуть незахищенними
